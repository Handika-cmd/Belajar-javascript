Penjelasan Singkat:

    1. Arithmetic Operators (Operasi Matematika)
         Tambah +, Kurang -, Kali *, Bagi /
         Modulo % (Sisa pembagian). Misal: 10 % 3 hasilnya 1. Sangat berguna untuk mengecek bilangan ganjil/genap.
         Increment ++ (Tambah 1), Decrement -- (Kurang 1)
         
    2. Comparison Operators (Operasi Perbandingan)
         Sama dengan == (Hanya ngecek nilai). Penting: Sebaiknya dihindari.
         Strict sama dengan === (Ngecek nilai DAN tipe data). Sangat direkomendasikan!
         Tidak sama dengan != / !==, Lebih besar >, Lebih kecil <, dst.

    3. Logical Operators (Operasi Logika)
         AND && (Harus semua true hasilnya baru true)
         OR || (Cukup satu true hasilnya sudah true)
         NOT ! (Membalikkan nilai, true jadi false)
